The official route

What Lever gives you directly

Every Lever job site answers as JSON: one GET per company returns the current postings with location, team, commitment and full text sections. It is free, unauthenticated and documented on Lever's own GitHub. As with every single-tenant API, coverage is on you: you need to know each company slug, and a closed posting simply vanishes from the list.

the official route, verbatim 
# {company} is the slug in jobs.lever.co/{company}
curl "https://api.lever.co/v0/postings/{company}?mode=json"

Before you ask

Questions buyers actually ask about Lever data

Does Lever have a public API?

Yes. Lever serves public job board data as JSON with no API key. The exact endpoint and a working request are in the «The official route» section above. What no single endpoint gives you is the whole market: you still need to know every company board, fetch each one, and notice yourself when a posting disappears.

How many Lever job postings are live right now?

As of the last refresh (21 Nov 2026), our index holds 74,786 active Lever postings across 1,959 companies. A posting counts as active only while it appears on the employer's own board; when it leaves the source we mark it closed, we never let it age out silently.
