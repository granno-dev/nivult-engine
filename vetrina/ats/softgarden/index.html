The official route

What Softgarden gives you directly

Softgarden career pages load their listings through JSON endpoints used by the embedded job widget. Those endpoints are public in practice but not documented as a public API, so we treat them as unstable and read them with care. There is no official public listing API that we could verify.

Questions buyers actually ask about Softgarden data

Does Softgarden have a public API?

There is no documented public job board API for Softgarden that we could verify. Our index reads the public career pages directly, the same pages candidates see.

How many Softgarden job postings are live right now?

As of the last refresh (22 Nov 2026), our index holds 4,539 active Softgarden postings across 65 companies. A posting counts as active only while it appears on the employer's own board; when it leaves the source we mark it closed, we never let it age out silently.
