The official route

What SmartRecruiters gives you directly

SmartRecruiters documents a public Posting API: one GET per company returns the active postings as JSON, paginated at 100 per page, with location, department and employment type already structured. No key is needed for the public postings of a company. You still need the list of company identifiers, and the API never tells you a posting closed: it just stops returning it.

the official route, verbatim 
# {companyId} from the company's careers page URL
curl "https://api.smartrecruiters.com/v1/companies/{companyId}/postings?limit=100"

Before you ask

Questions buyers actually ask about SmartRecruiters data

Does SmartRecruiters have a public API?

Yes. SmartRecruiters serves public job board data as JSON with no API key. The exact endpoint and a working request are in the «The official route» section above. What no single endpoint gives you is the whole market: you still need to know every company board, fetch each one, and notice yourself when a posting disappears.

How many SmartRecruiters job postings are live right now?

As of the last refresh (20 Oct 2026), our index holds 385,232 active SmartRecruiters postings across 5,018 companies. A posting counts as active only while it appears on the employer's own board; when it leaves the source we mark it closed, we never let it age out silently.
