Nivult API

          
Query live job postings and company intelligence from employer career systems and public employment portals. The API is versioned, JSON-first and uses keyset pagination.

          
BASE URLhttps://api.nivult.com

          
Quickstart

          
Create an active key in API Keys, then send it in the X-Api-Key header. Never put the key in the URL.

          

          

          
Response envelope

          
Paginated endpoints return data, next_cursor and count_page. Keep requesting until next_cursor is null.

          
{
  "data": [{ "id": "...", "title": "Data Engineer" }],
  "next_cursor": "opaque-keyset-cursor",
  "count_page": 1
}

        


        

          
Authentication & metering

          
Direct API clients authenticate with X-Api-Key. Revoked keys stop working immediately. Usage is shared across all account keys, including revoked keys.

          
ResourceCostEntitlement

            
/v1/jobs1 credit per returned jobEvery plan

            
/v1/companies and company detail3 credits per returned companyEvery plan

            
/v1/changes1 credit per returned eventActive Growth, 100K credits/month

            
/v1/coverage0 credits (rate-limited)Every plan

            
/v1/exports/latest and file downloads0 credits (included)Active Scale, 500K credits/month

            
/v1/usage0 credits (rate-limited)Every plan (works at zero balance)

          

          
Pay per result, not per call. Empty results and errors cost 0 credits. Usage, coverage and Daily bulk are unmetered service endpoints and return X-Credits-Charged: 0; authentication, rate limits and plan entitlements still apply. Plan or trial allowance is spent before purchased credits. Top-ups never expire and do not unlock Delta or Daily bulk.

          
For direct accounts, the effective page limit is also capped by the available balance and the per-record cost.

        


        

          
Jobs

          
GET/v1/jobs

          
Returns live job postings. Each returned record costs 1 credit. Keyword filters accept comma-separated values and are ORed.

          
Core parameters

          
ParameterDescription

            
countryISO 3166-1 alpha-2 country code, e.g. DE,FR.

            
categoryJob family.

            
atsSource platform slug. bundesagentur is accepted alone as a public alias for bundesanstellung.

            
exclude_atsExclude source slugs. If a value appears in both ats and exclude_ats, it is excluded.

            
senioritySeniority, e.g. mid,senior.

            
remoteremote, hybrid or onsite.

            
languagePosting language, e.g. en,it.

            
qFull text over title and description; all terms are required (AND).

            
q_anyAt least one of up to 15 comma-separated keywords (OR). Can be combined with q.

            
titleFull text restricted to the job title; all terms required.

            
technologyCase-insensitive exact match on normalized technologies.

            
posted_afterPosted at or after an ISO 8601 date/timestamp, inclusive.

            
posted_beforePosted strictly before an ISO 8601 date/timestamp, exclusive.

            
limitPage size: default 100, minimum 1, maximum 500. Balance can reduce the effective limit.

            
cursorOpaque keyset cursor returned by next_cursor.

          

          
v2 parameters

          
ParameterDescription

            
source_typedirect, aggregator, staffing or public_board.

            
companyFull-text match on employer name.

            
company_slugEmployer/source slug.

            
company_domainEmployer domain; scheme, www and path are normalized.

            
cityCity.

            
stateState or region.

            
employment_typeEmployment type.

            
departmentDepartment.

            
skillsExtracted skills, e.g. MBSE,SysML.

            
salary_currencySalary currency, e.g. EUR.

            
has_salarytrue or false; whether observed salary_min or salary_max exists.

            
salary_minLower bound on observed salary_min, number ≥ 0.

            
salary_maxUpper bound on observed salary_max, number ≥ 0.

This query asks for direct hybrid mid-level Data & Analytics jobs in Paris with SAP, a salary range and a November posting window.

          

          

          
More query patterns

          
GET /v1/jobs?q_any=MBSE,SysML,CATIA&exclude_ats=jsonld&has_salary=true&salary_min=50000&salary_max=80000&salary_currency=EUR

GET /v1/jobs?company_domain=dixonvalve.com&source_type=direct&department=Engineering

GET /v1/jobs?city=Berlin&state=Berlin&employment_type=full_time&posted_after=2026-11-01T00:00:00Z&posted_before=2026-12-01T00:00:00Z

        


        

          
Companies

          
GET/v1/companies

          
Returns company records keyed by ATS + company_slug. Each returned record costs 3 credits.

          
ParameterDescription

            
countryCountry of the company record, not every posting location.

            
industryExact industry value.

            
qCase-insensitive company-name search.

            
technologyCompany-level technology aggregate.

            
employees_minMinimum headcount.

            
employees_maxMaximum headcount.

            
limit, cursorSame pagination contract as Jobs.

          

          

          

        


        

          
Company detail

          
GET/v1/companies/{piattaforma}/{slug}

          
Returns one company for 3 credits. A missing company or any other error costs 0 credits.

          
Path parameterDescription

            
piattaformaATS/source identifier, e.g. greenhouse.

            
slugEmployer slug within that ATS.

          

          

          
Selected enriched fields include declared provenance metadata. It is not present on every field.

        


        

          
Changes / Delta feed

          
GET/v1/changes?since={ISO timestamp}

          
Returns new, updated and closed events so your local index stays synchronized. Requires an active Growth subscription or higher with at least 100,000 credits/month.

          
ParameterDescription

            
sinceRequired. ISO 8601 timestamp within the retained seven-day history.

            
limitPage size, capped by balance.

            
cursorPaginates the current response; it is not the next since value.

          

          

          

          
Use an ISO timestamp from your previous successful sync for the next since. If retention has expired, the API returns delta_retention_exceeded with action=resync and resync_required=true.

        


        

          
Coverage

          
GET/v1/coverage

          
Returns coverage percentages from 0 to 100 for the documented set of posting and company fields measured on the latest export. It is not a schema of every response field. Costs 0 credits on every plan, including at zero balance; key authentication and rate limits still apply.

          
{
  "category": 97.0,
  "description": 95.6,
  "country": 89.4,
  "remote": 52.4,
  "salary_observed": 23.2,
  "company:headquarters": 93.9
}

        


        

          
Daily exports

          
GET/v1/exports/latestand/v1/exports/latest/{nome}

          
The manifest returns metadata for the latest export and file downloads return JSONL gzip. Both cost 0 credits and require an active Scale subscription or higher with at least 500,000 credits/month, including at zero API balance. Top-ups alone do not unlock this entitlement.

          
ResourceDescription

            
/v1/exports/latestLatest manifest, with row counts and file paths.

            
offerteDaily postings JSONL gzip.

            
aziendeDaily companies JSONL gzip.

Reports current usage and balance without changing it. Costs 0 credits on every plan and remains available at zero balance; key authentication and rate limits still apply.

Errors & pagination

          
StatusMeaningWhat to do

            
400Invalid date, cursor or Delta retention.Correct parameters; on retention error, run a full resync.

            
401Missing, invalid or revoked key.Use an active key; create a replacement if needed.

            
403Required entitlement is missing.Upgrade to Growth for Delta or Scale for bulk.

            
404Company or export not found.Check ATS + slug or retry when the daily export is ready.

            
422Parameter validation failed.Fix types, ranges and allowed values, e.g. limit or salary.

            
429Rate limit exceeded, or insufficient credits on paid data endpoints. Usage, coverage and Daily bulk never return 429 for zero balance.Back off and honor Retry-After. For paid data, add credits or reduce the page size; no error charge.

            
503Database, counter or query timeout.Retry with backoff; no error charge.

          

          
Credit error shape

          
{
  "detail": {
    "error": "monthly and purchased credits exhausted",
    "monthly_credits": 500,
    "purchased_credits": 0,
    "usage_month": "2026-11-01"
  }
}

          
Paginate safely

          
  • Use next_cursor exactly as returned; it is an opaque keyset cursor, not an offset.
  • Stop only when next_cursor is null.
  • For Delta, keep the previous successful sync timestamp separately for the next since.
